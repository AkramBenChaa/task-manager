# 📋 Simple Task Manager (CLI)

A lightweight **Command-Line Interface (CLI)** To-Do List application built with **Python**. It allows users to manage daily tasks with persistent file storage (`tasks.txt`).

---

## ✨ Features

- ➕ **Add Tasks**: Easily append new tasks to your list.
- 📜 **View Tasks**: Display all current tasks with numbered indexing.
- 🗑️ **Delete Tasks**: Remove completed or unwanted tasks by their number.
- 💾 **Data Persistence**: Automatically saves and loads tasks from a local `tasks.txt` file.
- 🛡️ **Error Handling**: Gracefully handles invalid inputs and file handling edge cases.
